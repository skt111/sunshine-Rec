# 信息缺失检查清单 (Information Checklists)

> **用途**: 架构规划前的完整性检查，确保基于完整信息进行规划

---

## 需求层检查 (Requirement Checklist)

```markdown
[ ] 需求目标是否明确且可量化？
[ ] 用户角色是否清晰定义？
[ ] 业务场景是否全面覆盖？
[ ] 边界条件是否明确定义？
[ ] 异常场景是否充分考虑？
[ ] 性能要求是否明确？
[ ] 安全要求是否明确？
```

### 未通过时的挂起动作

| 检查项 | 未通过时的动作 |
|-------|---------------|
| 需求目标不明确 | 挂起，要求定义可衡量的目标 |
| 用户角色不清晰 | 挂起，询问 "这个功能给谁用？" |
| 业务场景未覆盖 | 挂起，要求补充场景说明 |
| 边界条件未定义 | 挂起，要求定义 IN/OUT 边界 |
| 异常场景未考虑 | 挂起，要求补充异常处理场景 |
| 性能要求未明确 | 挂起，询问 "对响应时间有要求吗？" |
| 安全要求未明确 | 挂起，询问 "是否需要权限控制？" |

---

## 技术层检查 (Technical Checklist)

```markdown
[ ] 现有代码是否已探查？
[ ] 调用链是否已溯源？
[ ] 依赖关系是否已梳理？
[ ] 数据结构是否已确认？
[ ] 状态机是否已定义？
[ ] 技术债务是否已评估？
```

### 未通过时的挂起动作

| 检查项 | 未通过时的动作 |
|-------|---------------|
| 现有代码未探查 | 挂起，要求先读取相关代码 |
| 调用链未溯源 | 挂起，要求先追溯调用链 |
| 依赖关系未梳理 | 挂起，要求先梳理依赖关系 |
| 数据结构未确认 | 挂起，要求先确认表结构/Entity |
| 状态机未定义 | 挂起，要求先定义状态流转 |
| 技术债务未评估 | 挂起，要求先评估技术债务 |

### 探查深度要求

| 需求类型 | 最小探查深度 | 必须探查的内容 |
|---------|-------------|---------------|
| **新增功能** | 3 层调用链 | Controller → Service → Entity |
| **功能修改** | 完整调用链 | 从入口到数据层的完整链路 |
| **Bug 排查** | 完整调用链 + 状态机 | 调用链 + 相关状态流转 |
| **性能优化** | 完整调用链 + 数据流 | 调用链 + 数据查询/传输路径 |
| **架构重构** | 全量依赖图 | 所有相关模块及依赖关系 |

---

## 业务层检查 (Business Checklist)

```markdown
[ ] 业务规则是否清晰？
[ ] 权限控制是否明确？
[ ] 数据隔离是否定义？
[ ] 并发场景是否考虑？
[ ] 事务边界是否清晰？
[ ] 回滚机制是否设计？
```

### 未通过时的挂起动作

| 检查项 | 未通过时的动作 |
|-------|---------------|
| 业务规则不清晰 | 挂起，询问 "业务规则是什么？" |
| 权限控制不明确 | 挂起，询问 "是否需要权限控制？" |
| 数据隔离未定义 | 挂起，询问 "数据是否需要隔离？" |
| 并发场景未考虑 | 挂起，询问 "是否会有并发操作？" |
| 事务边界不清晰 | 挂起，要求定义事务边界 |
| 回滚机制未设计 | 挂起，要求设计回滚方案 |

---

## 跨端检查 (Cross-Platform Checklist)

```markdown
[ ] API 契约是否定义？
[ ] 字段类型是否对齐？
[ ] 错误码是否统一？
[ ] 超时控制是否设计？
[ ] 重试机制是否定义？
```

### 未通过时的挂起动作

| 检查项 | 未通过时的动作 |
|-------|---------------|
| API 契约未定义 | 挂起，要求先完成 API 契约推演 |
| 字段类型未对齐 | 挂起，要求前后端对齐字段定义 |
| 错误码未统一 | 挂起，要求统一错误码定义 |
| 超时控制未设计 | 挂起，要求定义超时策略 |
| 重试机制未定义 | 挂起，要求定义重试策略 |

---

## 信息缺失判定逻辑

```javascript
// 需求层判定
IF 需求描述 < 3 句话:
    挂起，建议启动 grill-me 模式
    
IF 缺少明确的目标用户:
    挂起，询问 "这个功能给谁用？"
    
IF 缺少核心业务场景:
    挂起，询问 "主要解决什么业务问题？"
    
IF 缺少数据规模信息:
    挂起，询问 "预期的数据量级是多少？"

// 技术层判定
IF 涉及现有代码修改 BUT 未读取相关代码:
    挂起，要求先读取代码
    
IF 涉及数据库修改 BUT 未查看表结构:
    挂起，要求先查看表结构
    
IF 涉及跨端交互 BUT 未查看现有接口:
    挂起，要求先查看接口定义

// 业务层判定
IF 涉及业务规则 BUT 未确认规则:
    挂起，询问 "业务规则是什么？"
    
IF 涉及权限控制 BUT 未定义权限:
    挂起，询问 "权限如何控制？"

// 跨端判定
IF 跨端交互 BUT API 契约未定义:
    挂起，要求先完成 API 契约推演
```
