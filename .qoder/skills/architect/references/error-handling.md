# Architect Skill - Error Handling & Circuit Breaker

> 本文件为 architect skill 的详细错误处理参考，避免主 skill Token 膨胀。

## 错误处理级别

| 场景 | 错误处理级别 | 说明 |
|-----|------------|------|
| 跨端新功能 | 完整错误处理 | 执行所有熔断检查 |
| 单端新功能 | 标准错误处理 | 执行核心熔断检查 |
| Bug 排查 | 简化错误处理 | 仅执行关键检查 |
| 用户声明 `--urgent` | 跳过熔断 | 输出警告，事后补充审计 |

## 常见错误场景

| 错误场景 | 症状 | 根因分析 | 处理方式 |
|---------|------|---------|---------|
| **需求歧义** | 用户描述模糊，多种理解并存 | 需求边界未定义 | 挂起，列出 2-3 种理解路径请求用户选择 |
| **plans.json 加载失败** | 文件不存在或格式损坏 | 文件被误删/覆盖 | 询问用户：创建新 plan 或恢复备份 |
| **跨端契约推演阻塞** | 无法确定 API 字段类型/结构 | 缺少现有接口参考 | 输出契约草案，标注 `[待确认]` 字段，请求用户补充 |
| **并发调研 Agent 超时** | Agent 执行超过 5 分钟未返回 | 调研范围过大或系统资源不足 | 主线程降级为单线程调研，记录超时日志 |
| **并发调研 Agent 发现矛盾** | 多个 Agent 返回冲突的调研结果 | 不同视角对同一实体的理解不一致 | 汇总矛盾点，向用户确认后决策 |
| **现有代码结构扫描失败** | 无法定位相关实体/状态机/API | 项目结构变更或索引过期 | 重新运行 `project-scanner.js` 更新雷达索引 |
| **用户强制跳过挂起** | 用户声明 `--urgent` 但未提供完整信息 | 紧急模式下信息不足 | 输出警告，标注缺失信息，事后补充审计 |

## 熔断机制 (Circuit Breaker)

当以下情况发生时，**立即熔断并请求人类介入**：

```markdown
熔断条件:
├─ 需求存在逻辑矛盾（如：既要 A 又要非 A）
├─ 连续 3 次意图对齐失败（用户反复修改需求）
├─ 跨端契约推演无法闭环（字段类型无法确定）
├─ 并发调研所有 Agent 均返回阻断
├─ 发现现有系统架构与需求根本冲突
└─ 信息缺失无法继续（新增）

熔断动作:
├─ 输出《熔断报告》：问题描述 + 已尝试方案 + 阻断原因
├─ 挂起当前流程
├─ 请求用户决策：
│   ├─ 选项 A: 调整需求范围
│   ├─ 选项 B: 修改现有架构（需授权）
│   └─ 选项 C: 强制继续（用户承担风险）
└─ 记录熔断事件到 当前 plan 详情"跨端交接"章节 + sys_scheduled_task_log（若为定时任务）
```

## Fallback 策略

| 主路径失败 | Fallback 路径 | 触发条件 |
|-----------|--------------|---------|
| 并发调研失败 | 单线程串行调研 | 所有 Agent 超时或返回错误 |
| 跨端契约推演失败 | 仅输出单端 plan | 无法确定跨端接口时 |
| 项目雷达索引失效 | 直接文件系统扫描 | `.project_radar.json` 损坏或缺失 |
| plan 详情写入失败 | 输出到终端 + 请求用户手动保存 | 文件权限问题 |
| 信息缺失无法继续 | 挂起询问用户（新增） | 关键信息缺失时 |

## 错误恢复流程

```markdown
Step 1: 捕获错误
├─ 记录错误类型、错误上下文、时间戳
└─ 输出友好错误信息（非原始堆栈）

Step 2: 判断严重程度
├─ 可恢复错误 → 执行 Fallback
└─ 不可恢复错误 → 触发熔断

Step 3: 记录恢复动作
├─ 在当前 plan 详情"跨端交接"章节追加错误恢复记录（.handoff_state.md 已退役为历史档案）
└─ 若为熔断，标注 `[熔断]` 标记

Step 4: 通知用户
├─ 输出恢复结果摘要
└─ 若需用户决策，提供选项列表
```

## 错误日志格式

```markdown
### [错误恢复记录] YYYY-MM-DD HH:mm:ss

**错误类型**: [需求歧义 / 加载失败 / 推演阻塞 / Agent 超时 / 信息缺失]
**错误上下文**: [具体描述]
**严重程度**: [可恢复 / 不可恢复]
**恢复动作**: [Fallback 路径 / 熔断 / 用户决策]
**恢复结果**: [成功 / 失败 / 等待用户]
```
