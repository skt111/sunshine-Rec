# 附录C：设计参考（员工入职引导平台）

> 定位：**背景性设计参考**——帮助理解系统结构与联动关系；**具体需求以主文档与附录A/B 为准**（本附录只引不抄——单源化）。
> 配套材料：主文档《员工入职引导平台需求文档》v1.0。

## 1. 系统上下文

```
[宿主系统/门户] ──(免登 token)──▶ [入职引导平台]
                                   ├── 前端（Vue3 管理端，9 页面）
                                   ├── 后端（Spring Boot 单服务）
                                   │     ├── HR 库（employee 只读——联查/部门过滤/工号校验）
                                   │     ├── 平台库（10 表读写——业务主数据）
                                   │     └── 文件存储（材料文件——仅存 storage_key，下载鉴权流式）
                                   └── OA 消息推送（外部——2 端点，异步）
```

## 2. 领域模型（表关系简图）

```
employee(只读)
   ▲ oprid 引用（应用层，无物理外键）
   ├── pairing(newcomer_oprid) ──┬── task(pairing_id)          # 配对=入职启动点（任务快照生成）
   │                             └── feedback(pairing_id)       # 双向互评（每方向 1 条）
   ├── mentor(oprid 唯一) ◀── pairing(mentor_id)                # 导师库；负载=ACTIVE 配对计数
   ├── material(oprid) ────────▶ operation_log(material_id)     # 材料+留痕（审核/下载）
   ├── course ◀── enrollment(course_id, oprid)                  # 课程↔报名（UK 去重）
   └── reminder_log(receiver_oprid)                             # 提醒记录（幂等键=id）
```

## 3. 关键联动机制

### 3.1 入职启动链（配对 → 任务 → 提醒）

```
HR 建配对 ──[同一事务]──▶ ①task 实例生成（模板快照：items→逐条 task 行）
                        └▶ ②reminder_log 写 PENDING（配对通知）
        ──[事务提交后异步]──▶ ③调 OA 2.1（幂等键=提醒 id）
                               └─成功▶ SENT；失败▶ FAILED（可重推）
```

### 3.2 材料审核链（含隐私留痕）

```
新人提交 ──▶ material(SUBMITTED) ──▶ 审核台
   批准 ──▶ APPROVED（进归档页）
   驳回 ──▶ REJECTED(reason) ──[异步]──▶ OA 材料驳回提醒
   重提 ──▶ SUBMITTED(resubmit_count+1)
下载 ──▶ 鉴权（角色+范围）──▶ 流式转发 ──▶ operation_log(DOWNLOAD)
```

### 3.3 负载提示链

```
配对弹窗 ──▶ 导师下拉（实时聚合：SELECT mentor, COUNT(pairing ACTIVE)）
       ──▶ 负载 ≥ 阈值（§九 onboarding.load-threshold，默认 5）→ 黄色提示（不阻断）
```

## 4. 核心设计原则（编号）

1. **配对即启动**：入职流程的唯一触发点=配对创建（避免"任务凭空生成"的多入口混乱）；
2. **快照隔离**：模板可演进，实例不变（历史可追溯）；
3. **强一致/最终一致分界**：业务数据强一致（配对/任务/审核同事务）；通知最终一致（异步+幂等+可重推）；
4. **隐私默认收紧**：敏感字段默认不给（storage_key 不下发；列表不含文件内容）；下载必须鉴权+留痕；
5. **唯一性双保险**：应用层拦截 + 数据库唯一索引（配对 ACTIVE / 报名 / 互评方向）；
6. **数据范围服务端强制**：前端隐藏仅为体验，权限判定一律服务端。

## 5. 关键联动点速查表

| 联动关系 | 实现方式 |
|---------|---------|
| 配对 → 任务实例 | 同事务；模板 items JSON → 逐条 insert（快照） |
| 配对 → 提醒 | 同事务写 reminder_log；提交后异步调 OA（幂等键=id） |
| 驳回 → 提醒 | 审核事务提交后异步（同上） |
| 导师负载 | 实时聚合计数（不入库） |
| 材料下载 | 鉴权 → 流式转发 → operation_log |
| 进度完成度 | 聚合查询（DONE 数/总数），单 SQL 禁循环 |
