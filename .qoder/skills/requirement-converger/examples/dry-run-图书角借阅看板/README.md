## 使用建议

### 作为 AI Agent 任务输入

1. **阅读顺序**: 主文档（§一~三 全局）→ §四 功能需求 → 附录（按需查阅）；
2. **任务拆分参考**: 1 个页面 + 基础设施 = **2 个可并行工作流**（见下）；
3. **验收依据**: 主文档 §八（验收清单 + 端到端场景 + 构建门禁）。

### ★ 可并行工作流划分线索

| 工作流 | 域 | 含模块 | 可并行性 | 依赖 |
|--------|-----|--------|---------|------|
| W0 基础设施 | 工程骨架 / 认证接入 / 统一请求层 | 工程搭建、token 接入、请求封装、布局框架 | **必须最先** | — |
| W1 借阅台账 | 借阅登记 / 清单查询 / OA 通知 | 借阅看板页、借阅 API、OA 客户端 | 可并行（与 W0 后半程重叠） | W0 的请求层与认证（共享资产，最早波次交付） |

> 共享资产提示: 统一请求层与认证接入被 W1 全部页面引用——必须在最早波次交付；OA 客户端封装为 W1 内部共享单元。

## 硬约束（🚨 红线——可直接转化为审计检查项）

- 🚨 **禁改现有 HR 表**：employee 表**只读**；本次**唯一 DDL 授权 = 新建 book_loan 表**，其余严禁任何 DDL；
- 🚨 **OA 为外部系统（不开发）**：仅按附录B 契约对接；地址与密钥由环境供给，**禁止硬编码**；
- 🚨 **接口自行设计**：本包不含既有实现坐标；前后端接口由开发方设计并冻结为契约；
- 🚨 **架构红线**：页面组件禁止直调 axios/fetch（必须经 API 封装层）；前后端字段命名 snake_case。

## 需求覆盖范围（速览）

- **页面**：1 个（借阅看板 `/library/board`）
- **技术栈**：前端 Vue 3.5 + Element Plus；后端 Spring Boot 2.7 + MyBatis-Plus；OA 推送为外部系统
- **数据表**：2 张（新建 book_loan + 现有只读 employee）
- **外部对接**：OA 消息推送 2 端点
- **验收**：§八 验收清单 + §十一 验证手段矩阵（L0 构建 / L2 冒烟 / L3 联调）
