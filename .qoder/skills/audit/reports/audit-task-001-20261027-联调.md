# 跨端代码审查报告 · task-001 联调

## 一、联调结论（第一性原理）

```
现象：前端统计全 0 + "登录已失效"
问题1：前端有没有发请求？ → 有（收到后端 JSON 才能显示该文案）
问题2：为什么失败？ → LoginInterceptor 要求 token 非空
问题3：浏览器为何无 token？ → 本地未登录主系统（localStorage 为空）
结论：不是"前端没调后端"，而是"调了被 401 挡回"
```

修复：`supply-radar.auth.enabled=false`（WebMvcConfig 开关）→ 无 token 验证通过：
- `/statistics` → success, monitored=10, total=2902
- `/companies` → success, 20 家
- `/events?eventType=TALK` → success, total=1833

## 二、P0（6 条，阻断）

### P0-1 详情接口缺 `eventTitle`，详情抽屉标题必然空白
- 证据：`supplyradar/dto/EventDetailVO.java:14-84`（无 eventTitle）/ `service/EventService.java:66-67`（BeanUtils 同名复制）/ `SupplyDetailDrawer.vue:21`（读 detail.eventTitle）
- 建议：EventDetailVO 补 `private String eventTitle;`
- 连带：11 项详情要素验收不通过

### P0-2 统计缺 `hasRegistrationUrl`，勾选后统计与列表不一致
- 证据：`controller/StatisticsController.java:31-46`（无该参数）vs `EventController.java:52`（有）/ `SupplyRadar.vue:233,302-304`（共用 query）
- 建议：补参数 + 集成测试断言 `statistics.totalEventCount == events.total`

### P0-3 分类计数受 `category` 自过滤，点击页签后其余计数归零
- 证据：`StatisticsService.java:49` + `EventQueryBuilder.java:42-48,131-136`（category 进入聚合 WHERE）/ `SupplyRadar.vue:223,330-334`
- 建议：分类计数前 `sub.setCategory(null)`

### P0-4 分组 `recentEvents` 丢 5 个筛选条件
- 证据：`service/GroupService.java:116-120,130-146`（copyForRecent 缺 companyId/companyName/companyCategory/registrationStatus/hasRegistrationUrl）
- 建议：改"全量复制 + 只清 schoolIds/page/size/groupBy"

### P0-5 `auth.enabled=false` 使全部 `/api/**` 裸奔且无 profile 隔离
- 证据：`config/WebMvcConfig.java:19-27`（false → 不注册拦截器）/ `application.yml:56-59`（显式 false）/ 注释中 `/api/probe/open` 实际不存在
- 建议：yml 默认 true；本地用 `--supply-radar.auth.enabled=false` 或 local profile 覆盖；写接口（POST /crawl-tasks）保留保护
- 连带：生产若沿用 → 2902 条数据匿名可读、任何人可触发爬虫

### P0-6 `verification_status` 写入非法值 `NEEDS_REVIEW`（合法 `NEED_REVIEW`）——**已实测确认**
- 实测：`SELECT verification_status, COUNT(*)` → `NEEDS_REVIEW 1761` / `VERIFIED 1141`
- 枚举：`enums/VerificationStatus.java:10` = `NEED_REVIEW`
- 写入点：`CrawlExecutor.java:324`、`FrontpageCrawler.java:325`、`ThuCicCrawler.java:157`、`PlaywrightHtmlCrawler.java:180,275,391`
- 统计漏计：`StatisticsService.java:85`；前端筛选 `constants/supplyRadar.js:110-115`、`SupplyRadarFilter.vue:91`
- 建议：统一用 `VerificationStatus.NEED_REVIEW.getCode()`；`UPDATE employment_event SET verification_status='NEED_REVIEW' WHERE verification_status='NEEDS_REVIEW'`；入库前加枚举白名单校验
