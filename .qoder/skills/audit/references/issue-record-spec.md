# 问题记录规范

> 从 `audit/SKILL.md` 问题记录分级展开的详细格式要求。

## P0 问题必填字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 编号 | `P0-001` 格式 | P0-001 |
| 描述 | 问题现象一句话描述 | 用户登录时 token 未校验导致越权 |
| 源文件 | 问题所在文件路径 | `<端目录>/.../UserController.java` |
| 代码位置 | 文件:行号 | `UserController.java:45` |
| 代码块 | 问题代码片段 | ```java ... ``` |
| 根因 | 问题产生的根本原因 | 缺少 `@PreAuthorize` 注解 |
| 修复建议 | 具体修复方案 | 添加权限注解并补充单元测试 |
| 连带影响 | 修改后对其他模块的影响 | 需要同步更新前端拦截器 |
| 影响范围 | 受影响的功能/模块列表 | 用户管理、权限校验 |
| 修复后代码 | 修复后的完整代码片段 | ```java ... ``` |

## P1 问题必填字段

| 字段 | 说明 |
|------|------|
| 编号 | `P1-001` 格式 |
| 描述 | 问题现象描述 |
| 源文件 | 文件路径 |
| 代码位置 | 文件:行号 |
| 修复建议 | 修复方案 |
| 连带影响 | （可选）影响分析 |

## P2 问题必填字段

| 字段 | 说明 |
|------|------|
| 编号 | `P2-001` 格式 |
| 描述 | 问题现象描述 |
| 源文件 | 文件路径 |
| 代码位置 | 文件:行号 |
