# 代码审计检查清单

> 从 `audit/SKILL.md` 审计重点维度展开的详细检查项。
>
> **V2.8.0 触发标注**: 各组标注适用触发（【始终】= A1+ 必查；【触发：xxx】= 命中才查）——与 SKILL「审计深度分级」对接；触发未命中组不查（减无关面，不降应有面）。

## P0 级检查项（阻断级）

### 业务逻辑正确性【始终】

- [ ] 需求实现完整，无遗漏分支
- [ ] 边界条件覆盖（空值、极值、并发）
- [ ] 状态流转符合预期（无死锁、无跳跃）

### 功能规则流转【始终】

- [ ] 调用关系正确（无循环依赖、无悬空调用）
- [ ] 数据流转完整（写入→读取闭环可追踪）
- [ ] 状态变更符合状态机定义

### 连带影响分析【始终】

- [ ] 修改是否影响其他模块的输入/输出
- [ ] 共享数据结构变更是否通知消费方
- [ ] 配置变更是否需要联动更新
- [ ] 数据库 Schema 变更是否需要同步迁移脚本

### 数据对齐验证【触发：跨端/协议变更】

- [ ] 跨端状态同步一致（前端展示 ↔ 后端数据）
- [ ] 协议语义一致（字段命名、类型、单位、格式）
- [ ] 接口契约与 VO/DTO 字段一一对应

## P1 级检查项（建议修复）

### 跨层契约一致性【触发：跨端变更】

- [ ] 前后端接口 URL/Method/参数匹配
- [ ] VO/DTO 字段名、类型、可空性对应
- [ ] 错误码定义一致

### 测试证据保真（task-109 W6）【触发：plan 声明测试/验证证据】

- [ ] 测试触达被测对象本体（只测依赖库 = 绕过代理层缺陷）
- [ ] 测试使用真实消息结构（伪造结构会掩盖字段路径缺陷）
- [ ] 验证证据链（2026-09-11）：plan 详情「验证证据」节与检查点「场景验证记录/测试豁免记录」一致、引用可达（非存量）——缺失/不一致 → P1（01 §6.3 三段链）
- [ ] 豁免正当性（核心逻辑无理由豁免 → P1；检查点「测试豁免记录」有据）
- [ ] 三态出口记录一致（执行/补建/豁免——与 god 阶段 4 输出一致）

### 失败显式化（2026-09-15 复盘吸收）【触发：外部依赖/配置变更】

- [ ] 外部依赖（配置中心/DB/第三方 API）失败路径有显式告警/日志（静默降级、吞异常 → P1）
- [ ] 配置拉取失败不静默（empty/失败必须可观测——日志/告警；显式声明的降级策略除外，须有设计理由）
- [ ] fallback 路径有日志与可追溯记录（静默 fallback → 标记）

### 空值/类型检查（降级为 P2 场景）【始终（最低优先）】

- [ ] null 防护（Optional/默认值/判空）
- [ ] 类型匹配（序列化注解、反序列化容错）
- [ ] 集合空值处理（空集合 vs null）

## P2 级检查项（可选优化）

- [ ] 命名规范一致性
- [ ] 注释完整性
- [ ] 日志级别合理性
- [ ] 异常信息是否包含上下文
