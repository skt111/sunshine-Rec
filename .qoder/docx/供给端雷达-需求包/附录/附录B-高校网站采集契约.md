# 附录B：高校就业网站采集契约

> **定位声明**: 54 所高校就业信息网为**外部既有系统，本包不开发**；本系统为采集方（只读）。来源：`主要高校就业招聘网站清单_修正版.md`（2026-10-26）。
> **服务职责（外部）**: 公开发布招聘公告/宣讲会/双选会/招聘日历等页面。
> **对接方职责（本系统）**: 合规抓取公开页面、解析结构化字段、去重入库；不绕过任何访问控制。
> **传输基线**: HTTP/HTTPS GET；HTML 响应（静态直采）或需 JS 渲染（Playwright）。
> **地址与凭据**: 各站 URL 见高校清单；**无需鉴权**（公开页面）。清单中标注的登录/企业注册入口**不采集**。

---

## 1. 鉴权与通用约定

- **鉴权**: 无（公开发布页面）。清单明确「公开信息入口」与「登录/企业注册/管理后台入口」分离——后者**不采集**。
- **响应形态**: HTML 文档（列表页 + 详情页）。非统一 API。
- **编码**: 可能 UTF-8 或 GBK，解析前按页面 `charset` 判定。
- **合规**: 采集前读取 `robots.txt`，遵守 `Crawl-delay`；UA 为 `SunshineRecBot/1.0 (+contact)`、请求间隔 ≥2s、超时 30s、失败重试 2 次（与主文档 §9 一致）。
- **统一响应差异声明**: 本外部系统无 JSON 响应壳，解析结果经本系统 `{status,message,result}` 壳返回前端（**禁止混用外部结构**）。

---

## 2. 采集端点契约（按页面类型——站点数 54）

> "端点"= 每所高校的「栏目列表页 + 分页 + 详情页」组合。站点配置存 `university_site`。

### 2.1 列表页（栏目发现 + 活动候选）

- **入口类型**: 就业活动 / 招聘活动 / 就业信息 / 招聘信息 / 校园招聘 / 校园宣讲会 / 招聘会 / 双选会 / 通知公告 / 招聘日历 / 就业日历 / 企业进校活动。
- **栏目发现规则**: 🚨 **不得仅匹配"宣讲会/双选会"标题**；须按上述关键词白名单扫描候选栏目，再进入详情判断性质（支持"统一放在就业活动栏目"的站点）。
- **分页**: 识别"下一页"/页码/滚动加载（JS 站走 Playwright）。
- **提取**: 候选活动链接列表（标题 + 详情 URL + 可选发布时间）。

### 2.2 详情页（活动解析）

- **提取字段**: 活动名称 / 原始活动类型 / 活动日期 / 开始结束时间 / 场馆 / 地址 / 主办单位 / 相关企业 / 报名截止 / 报名链接 / 活动说明 / 发布时间 / 稳定活动 ID（如有）。
- **解析器策略**:
  - `GENERIC` 通用解析器（默认，覆盖多数结构）；
  - `SPECIFIC` 专用适配器（按 `school_code` 登记，处理特殊结构）。
- **渲染方式（方案 A 混合）**:
  - 默认 `HttpClient + Jsoup`（静态 HTML，快）；
  - 检测到内容为空/依赖 JS 渲染 → 切换 `Playwright`（Chromium）渲染后再解析；
  - Playwright 不可用 → 降级纯 Jsoup 并记录 `last_fail_reason`。

## 3. 集成时序

| 本系统动作 | 采集端点 | 时机/异常要求 |
|-----------|---------|--------------|
| 读取启用高校 | `university_site` | 任务开始前；`enabled=1` |
| 检查 robots.txt | 站点根 `/robots.txt` | 每站首次采集前；禁止项跳过 |
| 发现候选栏目 | 各栏目列表页 | 关键词白名单；失败仅记录该栏目 |
| 抓取列表 | 列表页 + 分页 | 间隔 ≥2s；超时 30s |
| 抓取详情 | 详情页 | 逐条；静→动渲染切换（§2.2） |
| 分类 | —（本地计算） | 规则 §3.7.9 |
| 去重更新 | —（本地写库） | 事务内：更新 + 写 history |
| 更新站点状态 | `university_site` | 成功→SUCCESS，部分→PARTIAL，失败→FAILED + 原因 |

## 4. 对接注意事项（编号）

| # | 事项 |
|---|------|
| 1 | **双层语义**: 外部为 HTML 非 JSON；解析产物由本系统统一壳返回，禁止把原始 HTML 直出前端 |
| 2 | **幂等可重入**: 幂等键 = `remote_id`（有）→ 否则 `fingerprint`；重复采集更新不新增 |
| 3 | **异步语义**: 采集任务"受理 ≠ 完成"；终态以 `crawl_task.status` 为准 |
| 4 | **一致性边界**: 单活动更新+变更历史须**同事务**（强一致）；任务级整体为**最终一致**（允许部分成功） |
| 5 | **地址与凭据**: URL 来自清单；无需密钥；数据库凭据环境供给（禁硬编码） |
| 6 | **失败隔离**: 单校失败不中断（B1）；失败不删除原数据（D5） |
| 7 | **访问控制**: 遇登录墙/验证码/403 → 停止该站自动尝试并记录，**不绕过** |
| 8 | **频率与礼仪**: 请求间隔 ≥2s、超时 30s、重试 2 次（指数退避）；尊重 `Crawl-delay` |
| 9 | **编码容错**: 按页面 charset 解码（UTF-8/GBK），避免乱码 |
| 10 | **HTML 清洗**: 入库前清洗正文（去脚本/样式），前端文本渲染 |
