## ★ 可并行工作流划分线索（最大效率来源——必须主动给出）

| 工作流 | 域 | 含模块/页面 | 可并行性 | 依赖 |
|--------|-----|------------|---------|------|
| **W0 基础设施** | 工程骨架 | Spring Boot 启动类 / 数据源 / 统一响应壳 / 全局异常 / SQL 建表脚本 / 前端路由与菜单接入 / API 封装层 | **必须最先**（共享资产最早波次交付） | — |
| **W1 采集层** | 域 A · Java 爬虫 | 站点配置 / 适配器体系 / 栏目发现 / 详情解析 / 分类规则 / 去重更新 / 定时任务 | 与 W2 可并行（接口契约由 W0 冻结后） | W0（表结构 + 配置键） |
| **W2 后端 API 层** | 域 B · REST 接口 | 7 个端点（schools / events / statistics / event detail / crawl-tasks ×2 / crawl-status）+ Mapper | 与 W1 可并行 | W0（表结构 + 响应壳） |
| **W3 前端展示层** | 域 C · Vue 页面 | 供给端雷达主页面（`SupplyRadarPage`）+ 9 个子组件（共 10 个组件，含主页面）+ 详情抽屉 + 采集任务面板 | 可并行（可先对 mock 契约开发） | W0（API 封装层） |

### 波次与依赖说明
- **波次 1（W0）**: 建表脚本、启动类、统一响应壳、前端路由骨架 → 全部下游共享。
- **波次 2（W1 / W2 / W3 并行）**: 三者仅通过 W0 冻结的**表结构 + 响应壳 + API 路径**耦合，可实现并行。
- **真实依赖**: W1 产数据 → W2 读数据 → W3 展示；但**编码期可用契约桩解耦**。端到端联调需三者齐备。
- **共享资产（严禁各自实现）**: 统一响应壳、分页结构、枚举常量、API 请求封装、日期格式化。

## 硬约束（🚨 必须在任务书中声明——每条可直接转审计检查项）

### 数据类
- 🚨 **禁止将 Excel 导出作为本模块数据交付方式**——数据必须入库。
- 🚨 **禁止伪造/用模拟数据污染正式库**——空数据时展示空态，不展示假统计。
- 🚨 **请求失败不得删除原有数据**——去重更新，不物理删除。

### 外部类
- 🚨 **禁止用 Python 实现采集**——采集必须 Java。
- 🚨 **禁止绕过访问控制**——遇登录/验证码/限制立即停止并记录，不破解。
- 🚨 **禁止自行编造高校网址**——严格以清单为准。

### 接口类
- 🚨 **禁止前后端单侧改字段名**——契约以附录A/主文档 §六 为准。
- 🚨 **禁止在未完成采集时提前显示"成功"**——任务状态以数据库终态为准。
- 🚨 **分页必须后端处理**——禁止一次性加载全部高校活动。

### 安全类
- 🚨 **禁止硬编码密钥/口令**——数据库凭据经环境供给。
- 🚨 **禁止拼接 SQL**——查询条件必须参数化，防 SQL 注入。
- 🚨 **禁止修改现有系统其他模块**——仅增量开发「供给端雷达」相关。
