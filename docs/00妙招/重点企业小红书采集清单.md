## 二、每家取 Top10 的判定口径

系统里选企业后，「热点排行」就是该企业的榜；默认按**综合互动**（点赞×1 + 收藏×2 + 评论×3）。

1. 先按**点赞**看谁最热（列表页脚本只能拿到点赞，最稳）；
2. 对前 10 条打开详情点脚本 B，补收藏/评论 → 综合榜自动重算；
3. 样本 <10 条时页面会标「样本不足」，此时不要下结论；
4. 榜单会显示 `样本数 / 总数` 与 `指标来源`，写进周报时一起带上。

## 三、导入后要做的三件事

1. **补主题标签**：校招 / 实习 / 薪酬 / 培养 / 体验 —— 榜单一键切「主题」看分布；
2. **标归属**：企业官方号发的改为「企业官方内容」，学生发的是「用户讨论」，拿不准留「待核验」；
3. **核验链接**：隔天抽查 10 条，点开原文确认标题与内容一致（防止采到同名/搬运号）。

## 四、采集前先跑一次来源核验

页右上角「◍ 来源核验」→ 探测一次，确认当前结论仍是 `robots 禁止 / 需要登录`：
说明自动采集不可用，只能人工/半自动；若将来拿到平台授权，这里会显示 `允许访问`，那时再开自动同步。
