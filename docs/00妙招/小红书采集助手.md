# 小红书公开笔记 · 采集脚本（一个脚本走到底）

> 同一个脚本，在**列表页**用就抓当前屏点赞最高的 10 条；在**笔记详情页**用就抓这 1 条（带收藏、评论、摘要）。
> 只读你屏幕上已经渲染出来的内容，不发后台请求、不自动翻页、不碰登录/验证码。

## 一、怎么用（两种方式任选）

### 方式 1：控制台（最快，临时用）

1. 停在小红书页面（列表页或详情页）；
2. `F12` → `Console`，首次会拦粘贴，先手打 `allow pasting` 回车；
3. 粘贴下面**整段**（不带 `javascript:` 前缀）→ 回车；
4. 弹出「已复制 N 条」→ 去系统里 Ctrl+V；若弹出输入框，就是复制失败，框里内容已是全选状态，Ctrl+C。

### 方式 2：书签（长期用）

1. `Ctrl+D` 随便存个书签，名字 `小红书采集`，存到「书签栏」；
2. 右键该书签 → 修改/编辑 → 把网址换成 **`javascript:` + 下面整段**（前缀必须手打或直接粘进书签网址栏）；
3. 以后在页面点一下书签就行。

## 三、两种场景分别得到什么

| 你在哪 | 得到 | 说明 |
|---|---|---|
| 搜索结果页 / 话题页 / 账号主页 | **最多 10 条**，按点赞降序 | 只有链接、标题、点赞；标题里会夹作者名和时间，导入后建议清理 |
| 某条笔记详情页 | **1 条**，含摘要 + 点赞 + 收藏 + 评论 | 用来给 Top 几条补全指标；同一链接再导不会新建笔记，而是追加快照 |

## 四、导入

系统「雇主品牌雷达」→「⇪ 批量导入」→ **默认企业选对** → 粘贴 → 解析预览 → 导入。

- 同一链接重复导入：不报错，会追加一条指标快照并更新"最近观察时间"；
- 看不到的指标留空，不要填 0；
- 导入后按企业筛选，「热点排行」就是这家的榜。

## 五、边界

- 只读当前页面 DOM，不调接口、不自动滚动/翻页/批量打开；
- 平台出现验证码、403、429 立即停止；
- 系统只存链接、标题、摘要与可见指标，不存正文全文和图片视频。

## 六、字段对照

| 字段 | 必填 | 说明 |
|---|---|---|
| noteUrl | 是 | 小红书链接，系统按链接去重 |
| title | 是 | 页面标题（可能含作者/时间，导入后可清理） |
| contentSummary | 否 | 详情页才有，≤1000 字 |
| companyId | 否 | 不填则用导入弹窗里选的默认企业 |
| likeCount / favoriteCount / commentCount | 否 | 看不到就留空 |
| topicTags | 否 | 校园招聘 / 实习招聘 / 薪酬福利 … |
| ownerType | 否 | `OFFICIAL` / `USER_DISCUSSION` / `UNKNOWN` |
| verificationStatus | 否 | 默认 `PENDING` |
